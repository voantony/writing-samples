## Samples

1. **[Patch README for `@exalabs/ai-sdk`](samples/exa-ai-sdk-patch/README.md)**  
   Developer documentation for a compatibility patch: what is broken in the published package, what the patch changes, how it was tested (including a compat matrix), and how to apply it. The full patch repository, with tests and raw output, is at [github.com/voantony/exa-ai-sdk-patch](https://github.com/voantony/exa-ai-sdk-patch).

2. **[Writing install docs for AI coding agents](samples/writing-install-docs-for-ai-coding-agents.md)**  
   A short essay (October 2026) about writing an `AGENTS.md` install guide for [kindle-mtp-mount](https://github.com/voantony/kindle-mtp-mount), a macOS tool that mounts a USB Kindle in Finder. It covers which steps an agent may run, which ones a human has to do, and how to verify the real behaviour instead of a status flag.

3. **[Omni Core documentation](samples/omni-core-docs/)**  
   Volunteer documentation written against the Omni Core source in October 2026: a guide to reducing transaction fees, a reference for every `-omnidebug` log category, and a correction to the `redeemaddress` RPC docs. These pages are not official Omni Layer documentation and had not been merged when this portfolio was published.
